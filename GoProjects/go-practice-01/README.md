# Практическая работа № 2: Анализ статусов задач

В рамках второй практики была добавлена новая программа для обработки списка задач и подсчета их статусов.

**Что реализовано:**
- Функция `statusLabel` для перевода кодов статусов (`new`, `in_progress`, `done`) в понятные русские подписи с использованием `switch`.
- Функция `countStatus` для подсчета количества задач с определенным статусом.
- Использование срезов (`slice`), циклов `for range` и словаря (`map`) для сбора статистики.
- Вывод задач с нумерацией и фиксированный вывод статистики.

**Файл программы:** `cmd/task-summary/main.go`

**Команда для запуска:**
```bash
go run ./cmd/task-summary
