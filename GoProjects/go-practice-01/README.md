# Практическая работа № 2: Анализ статусов задач

В рамках второй практики была добавлена новая программа для обработки списка задач и подсчета их статусов.

**Что реализовано:**
- Функция `statusLabel` для перевода кодов статусов (`new`, `in_progress`, `done`) в понятные русские подписи с использованием `switch`.
- Функция `countStatus` для подсчета количества задач с определенным статусом.
- Использование срезов (`slice`), циклов `for range` и словаря (`map`) для сбора статистики.
- Вывод задач с нумерацией и фиксированный вывод статистики.

**Файл программы:** `cmd/task-summary/main.go`

**Команда для запуска:**
```bash
go run ./cmd/task-summary
```

# Практическая работа № 3: Модель задачи

В рамках третьей практики была реализована структура задачи с методами и функция поиска элемента по указателю.

**Что реализовано:**
- Структура `Task` с полями `ID`, `Title`, `Status` и `Priority`.
- Метод `Summary()` с получателем по значению для форматированного вывода информации о задаче.
- Методы `Complete()` и `SetPriority(priority int) bool` с получателем-указателем (`*Task`) для изменения состояния исходного объекта и проверки корректности приоритета (от 1 до 3).
- Функция `findTaskByID(tasks []Task, id int) *Task`, возвращающая указатель на элемент исходного среза или `nil` при отсутствии совпадений.
- Изменение найденной задачи по указателю, безопасная проверка на `nil` и подсчет завершенных задач.

**Файл программы:** `cmd/task-model/main.go`

**Команда для запуска:**
```bash
go run ./cmd/task-model
```

# Практическая работа № 4: Интерфейсы, ошибки и консольное приложение

В рамках четвёртой практики реализовано консольное приложение для управления задачами с использованием интерфейсов, хранения в памяти и обработки ошибок.

**Что реализовано:**
- Интерфейс `TaskStore`, определяющий контракт для операций над задачами (`Add`, `Get`, `Complete`, `Delete`, `List`).
- Реализация хранилища в памяти `MemoryStore` с сохранением уникальности выданных ID при удалении и возвратом безопасной копии среза в `List()`.
- Эталонные ошибки `ErrNotFound` и `ErrInvalid`, их оборачивание через `%w` и проверка с помощью `errors.Is`.
- Интерактивное консольное меню на базе `bufio.Scanner` с валидацией ввода (`strconv.Atoi`, `strings.TrimSpace`) и использованием `defer` при завершении работы.

**Файл программы:** `cmd/task-cli/main.go`

**Команда для запуска:**
```bash
go run ./cmd/task-cli
```
